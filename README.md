# mangacodex

「WEB3.0オワタからクロちゃんとまとめてみた」制作をCodex上で運用するためのプロジェクト基盤です。

## Repository Map

- `docs/00_governance/PROJECT_OPERATING_RULES.md`  
  最上位ルール（非交渉事項、品質ゲート、更新責務）。
- `docs/01_bible/CHARACTER_BIBLE.md`  
  キャラクター固定仕様（翔一・クロちゃん）。
- `docs/01_bible/STYLE_BIBLE.md`  
  画風・色・レイアウト禁止事項。
- `docs/02_workflows/TASK_BOARD.md`  
  優先タスクとセッション成果物定義。
- `docs/03_prompts/`  
  本番用プロンプト置き場（ページ単位）。
- `docs/04_references/FACT_LOG.md`  
  事実・数字ログ。
- `skills/`  
  Codex向け運用スキル（orchestrator / research / composition / prompt）。
- `samples/SAMPLE_EP_4P_PROMPTS.md`  
  イメージ確認用4ページ試作プロンプト。

## Start Here

1. `docs/00_governance/PROJECT_OPERATING_RULES.md` を読む
2. `docs/01_bible/` でキャラと画風固定事項を確認
3. `docs/02_workflows/TASK_BOARD.md` の優先タスクから実行
4. 必要に応じて `skills/` のSKILL.mdを参照して進行
