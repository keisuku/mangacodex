# PROJECT OPERATING RULES

このファイルは「WEB3.0オワタからクロちゃんとまとめてみた」制作の最上位運用ルールです。

## 1. プロジェクト目的
- 漫画制作を長期連載前提で継続可能な運用にする。
- キャラクター、画風、ストーリー整合性を壊さない。
- セッション跨ぎでも品質を維持する。

## 2. 非交渉ルール（抜粋）
- クロちゃんはロボ度HIGHを維持（右腕フルクローム、機械眼、顎メタリック等を省略しない）。
- 翔一の基本設定（42歳・眼鏡・モード運用）を維持。
- 本編画風は「冨樫型ハイブリッド＋モノクロ＋青シアン #00BCD4 ワンポイント」を維持。
- 確定事項は覆さない。改善提案は確定事項を壊さない範囲で行う。
- 修正依頼時は確認を挟まず、修正版を即時フル出力する。

## 3. セッション分業
- リサーチ: 数字・事実・時系列を確定する。
- 構成: ネーム、感情曲線、密度レベル、導線を設計する。
- プロンプト: 画像生成用の実行可能プロンプトを作成し反復する。

## 4. ファイル更新ルール
- 事実更新は `docs/04_references/FACT_LOG.md` を一次更新。
- 設定更新は `docs/01_bible/CHARACTER_BIBLE.md` / `STYLE_BIBLE.md` を更新。
- 進行更新は `docs/02_workflows/TASK_BOARD.md` を更新。
- 画像生成プロンプトは `docs/03_prompts/` にページ単位で保存。

## 5. 品質ゲート（出力前チェック）
- キャラ崩壊がないか。
- モード禁則（布団モード／天啓モード）違反がないか。
- シアン使用対象と量が適正か。
- レイアウト禁止事項違反がないか。
