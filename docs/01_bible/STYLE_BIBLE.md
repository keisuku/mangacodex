# STYLE BIBLE

## 本編スタイル
- 冨樫型ハイブリッド。
- セットアップ：ラフで荒い線。
- クライマックス：描き込み爆発。
- 色：モノクロベース + シアン #00BCD4 のみ。

## シアン使用先（限定）
- クロちゃんのロボ要素（髪飾り、脇腹マーク、機械眼、回路）。
- 翔一のスマホ画面光。

## 禁止レイアウト
- 横向きページ。
- 2x2固定グリッド。
- 縦長左半分見開き。
- 話者名ラベル（「翔一：」など）のセリフ埋め込み。

## 共通スタイル文（英語）
Black-and-white manga art with a distinctive contrast style — loose confident sketchy lines for setup panels (Togashi-style "lazy-genius" mode), explosive precision and hatching density for climactic moments. Monochrome base with a single spot color: cyan (#00BCD4) used ONLY for Kuro-chan's robot elements and Shoichi's smartphone screen glow.
